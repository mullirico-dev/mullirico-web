# MulliRico image assets

Place or replace the bakery images in this folder using these filenames:

- `sourdough-hero.jpg`
- `bread-1.jpg`
- `bread-2.jpg`
- `bread-3.jpg`
- `bread-4.jpg`
- `crumb.jpg`
- `label.jpg`

Current status:

- The initial app already includes working image files so the site builds immediately.
- `bread-1.jpg` through `bread-4.jpg` were copied from the repository root `/assets` folder you added.
- `sourdough-hero.jpg`, `crumb.jpg`, and `label.jpg` are temporary duplicates created from the available bread photos so the UI has complete placeholders.

Recommended replacements:

- `sourdough-hero.jpg`: the strongest full-loaf or styled bakery hero photo
- `crumb.jpg`: a close-up cross-section showing the crumb texture
- `label.jpg`: branded packaging, label, or styled product presentation
